# v0.33.0 candidate: explicit table preparation

Status: selected for version-specific checks, **not published**. Stable installers
remain v0.32.0. This batches three related user outcomes, not one release per feature.

| Need | Delivery | Boundary |
| --- | --- | --- |
| Exchange tab-separated tables without hand splitting quotes or multiline cells | `tsv-to-jsonl` / `jsonl-to-tsv` | Explicit quoted dialect; import strings, no delimiter/type guessing. |
| Select generated counts or numeric IDs exactly | `jsonl-where-int --pointer /count --equals 2` | Integer literals only, no float conversion/coercion; `-0` equals `0`. |
| Export records with an absent optional column | `jsonl-project --field-default NAME=JSON_LITERAL` / field `default_json` | Explicit literal only on absence; present null and strict fields stay unchanged. |

All three reuse native CLI/recipe/tool implementations. They add no dependency,
tool name, permission, model runtime, general query engine, session or automatic
memory. Examples, protocol coverage and installation checks are supporting work,
not extra feature counts. Each model tool starts from original input; only internal
ordered steps use intermediate results. Use the offline data commands when the
task should not send original input to a model.
